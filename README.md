# Chalk Talk (NFL)

Personal NFL power-ratings + betting/fantasy dashboard. Part of the SpoFi Network family of
dashboards (see the college Chalk Talk repo for the CFB version).

## What's in here

- **`ChalkTalk.html`** -- the actual dashboard. Single self-contained file (HTML/CSS/JS, no
  build step) -- this is what Netlify deploys. Ratings, games, odds, weather, and fantasy
  rosters are hardcoded JS arrays inside it, refreshed weekly by the pipeline below.
- **`pipeline/weekly_update.py`** -- run this once a week (Tuesdays, in-season) to pull fresh
  play-by-play, refit the power ratings, pull current odds, and print ready-to-paste JS for
  the `RATINGS`/`GAMES`/`BOOKS`/`CLOSING_RESULTS` blocks in `ChalkTalk.html`.
- **`pipeline/stadiums.py`** -- lat/lon + roof type per team, used by the pipeline's weather
  pull.
- **`pipeline/config_local.example.py`** -- copy to `pipeline/config_local.py` (gitignored)
  and fill in your real Odds API key before running the pipeline locally. Never commit
  `config_local.py` itself.

## Deploy workflow

Netlify is connected to this GitHub repo (Site settings -> Build & deploy -> Link repository),
publish directory `/`, no build command -- pushing to `main` deploys automatically. To ship a
dashboard change:

```
git add -A
git commit -m "describe the change"
git push
```

## Roster editing

Fantasy rosters (Sleeper/ESPN/Yahoo) are NOT auto-synced -- none of the three platforms are
polled live by the pipeline. Instead, `ChalkTalk.html` has a self-service roster editor built
into the Player Watch tab: add a player (autocompleted from Sleeper's public player list),
drop one, or flip starter/bench, right on the live site. Edits are saved per-browser
(`localStorage`) and layered on top of the hardcoded snapshot in the file -- they don't touch
this repo, so they survive independently of when this file was last pushed. "Reset to
snapshot" on that tab clears all manual edits for a league back to what's actually in the
file.

## Notes

- The Odds API key used by the pipeline is a personal key on a paid-ish free tier -- keep
  `config_local.py` out of git (already gitignored) and don't share this repo publicly with
  it exposed anywhere in history.
- `pipeline/*.parquet`, `week_odds.json`, `wx_*.json`, and `schedule_2026_full.csv` are
  regenerated by running the pipeline and are gitignored -- no need to version large,
  fast-changing cache files. `ChalkTalk.html` is the source of truth for what's actually
  live on the site.
